# CombatWeather

(For World of Warcraft - Forever)

Tired of not being able to find the boar killing you in a Dun Morogh snowstorm because it is turning your whole screen white?

This addon solves that problem by automatically adjusting the weather density based on combat state so you get to enjoy a clear screen when fighting and full immersion when not, all done seamlessly and without bother. It includes customisable options so you can fine tune your experience to  your taste.
